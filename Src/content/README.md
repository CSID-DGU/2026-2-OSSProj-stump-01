## 수종 카드 (`species-cards.json`)

기록이 적은 초기에도 나무 페이지에 볼거리가 있도록, 수종 특징과 계절 변화를 보여 준다.

### 고른 기준

서울시 가로수 위치 정보 2026년판을 `Src/backend/data/trees.py`로 정리한 결과(281,697그루)에서 그루 수 상위 수종을 골랐다.
`은행나무 암나무`는 `은행나무`에, `왕벚나무`는 `벚나무류`에 합쳤다. 상위 10종 카드가 전체 가로수의 약 94%를 덮는다.

| 순위 | 카드 | 원본 수종 이름 | 그루 수 |
|---|---|---|---|
| 1 | 은행나무 | 은행나무, 은행나무 암나무 | 99,045 |
| 2 | 양버즘나무 | 양버즘나무 | 43,646 |
| 3 | 느티나무 | 느티나무 | 40,123 |
| 4 | 벚나무 | 벚나무류, 왕벚나무 | 32,960 |
| 5 | 이팝나무 | 이팝나무 | 26,922 |
| 6 | 회화나무 | 회화나무 | 5,915 |
| 7 | 소나무 | 소나무 | 5,208 |
| 8 | 메타세쿼이아 | 메타세쿼이아 | 4,747 |
| 9 | 대왕참나무 | 대왕참나무 | 3,097 |
| 10 | 칠엽수 | 칠엽수 | 1,952 |

### 형식

```jsonc
{
  "id": "ginkgo",                      // 영어 소문자·하이픈. 화면·API에서 카드를 찾는 키
  "name": "은행나무",                   // 화면에 보이는 이름
  "aliases": ["은행나무", "은행나무 암나무"], // 가로수 데이터 trees.species 값. 이 값으로 카드를 찾는다
  "scientificName": "Ginkgo biloba",
  "family": "은행나무과",
  "leafType": "낙엽 겉씨식물",
  "seoulCount": 99045,                 // basis 기준 그루 수
  "rank": 1,
  "summary": "한두 문장 소개",
  "features": ["특징 3개"],
  "seasons": { "spring": "", "summer": "", "autumn": "", "winter": "" }
}
```

- 나무의 `trees.species` 값이 어떤 카드의 `aliases`에도 없으면 카드를 보여 주지 않는다(상위 10종 밖, 약 6%).
- 그루 수는 연도판이 바뀌면 다시 센다. 수종 이름이 바뀌면 `aliases`를 고친다.
- 같은 동·노선의 나무 수·돌보미 수는 이 파일이 아니라 API가 계산한다(`용어.md` 수종별 기본 콘텐츠).

### 쓰는 규칙

- 시민이 나무에 직접 조치(가지치기·약제·물주기)하도록 안내하는 문장은 넣지 않는다(`CLAUDE.md` 절대 규칙).
- 나무 나이는 가로수 데이터에 없으므로 쓰지 않는다.
- 안전과 관련된 사실(은행 열매 겉껍질 피부 자극, 칠엽수 열매 독성)은 적되 '만지지 말 것' 정도의 관찰 안내로만 쓴다.

## 돌보미 교육 (`education-cards.json`, `quiz-bank.json`)

돌보미가 활동 전에 읽는 교육 카드와, 이수 여부를 정하는 퀴즈 문제은행이다. 물주기 영역은 없다(`용어.md`).

### 영역과 출제 비율

| 영역 | id | 카드 | 문제은행 | 한 번에 내는 문항 |
|---|---|---|---|---|
| 안전 | `safety` | 4 | 8 | 3 |
| 신고 | `report` | 3 | 6 | 2 |
| 기록 | `record` | 3 | 6 | 2 |
| 폭염기 활동 | `heat` | 2 | 6 | 2 |
| 운영 | `operation` | 2 | 4 | 1 |
| 합계 | | 14 | 30 | 10 |

- 안전을 가장 많이 낸다. 통과 기준(8/10 이상 + 안전 문항 모두 정답, #10)에서 안전은 하나라도 틀리면 떨어지기 때문이다.
- 영역마다 문제은행을 출제 수의 두 배 이상 두어, 다시 볼 때 같은 문제만 나오지 않게 했다.
- 출제·채점·통과 기준은 #10 API가 정한다. 이 파일에는 영역별 문항 수(`quiz.areas[].count`)만 둔다.

### 형식

```jsonc
// education-cards.json
{
  "id": "safety-road",       // 영역-내용. 문제의 cardId가 이 값을 가리킨다
  "area": "safety",          // areas[].id
  "order": 1,                // 영역 안에서 보여 줄 순서
  "title": "도로 쪽으로 나가지 않는다",
  "body": "두세 문장 설명",
  "points": ["기억할 점 3개"]
}

// quiz-bank.json questions[]
{
  "id": "safety-01",
  "area": "safety",
  "cardId": "safety-road",   // 이 문제의 근거 카드. 틀렸을 때 다시 볼 카드로 보여 줄 수 있다
  "question": "문제",
  "choices": ["보기 4개"],
  "answer": 0,               // 정답 보기의 위치(0부터). 화면에서 보기를 섞으면 정답도 같이 옮긴다
  "explanation": "정답 풀이"
}
```

### 쓰는 규칙

- 시민이 나무에 직접 조치(가지치기·약제·비료·지지대)하는 것은 정답이 될 수 없다. 이런 행동은 오답 보기로만 쓰고, 정답은 항상 '살피고 기록하고 신고하기'다(`CLAUDE.md` 절대 규칙).
- 신고가 공개되지 않는다는 것, 봉사시간은 구청이 승인한 보고서로만 기록된다는 것은 서비스 규칙 그대로 쓴다.
- 지금 당장 사람이 다칠 수 있는 상황(쓰러지는 나무, 온열질환)은 앱 신고보다 119 전화를 먼저 안내한다. 앱 신고는 구청 처리 큐로 가서 바로 출동하지 않는다.
- 정답 위치는 보기 1~4번에 고르게 나눴다. 보기 순서에 뜻이 있는 문제(`heat-01` 온도 오름차순)만 순서를 유지했다.

### 기준값이 바뀌면 같이 고칠 곳

아래 숫자는 서비스 기준값을 그대로 옮겨 적었다. 구청 확인(#59) 뒤 값이 바뀌면 코드와 이 파일을 같이 고친다.

| 기준 | 값 | 코드 | 이 파일에서 쓰는 곳 |
|---|---|---|---|
| 위치 확인 거리 | 30m | `backend/citizen/records.ts` `LOCATION_CHECK_DISTANCE_M` | 카드 `record-verify`, 문제 `record-03` |
| 폭염 | 일 최고기온 33℃ 이상 | `backend/district/weather-logic.ts` `HEATWAVE_MAX_TEMP` | 카드 `heat-when`, 문제 `heat-01` |
| 폭염 날 피할 시간 | 11시~17시 전 | `HEAT_AVOID_FROM`, `HEAT_AVOID_UNTIL` | 카드 `heat-when`, 문제 `heat-02` |
| 활동 선택 항목 | 보호틀 정리 외 4개 | `frontend/citizen/src/content/recordOptions.ts` `ACTIVITY_OPTIONS` | 카드 `record-daily` |
| 활동 기간 | 1년 | `backend/citizen/applications.ts` `PERIOD_YEARS` | 카드 `operation-caregiver`, 문제 `operation-01` |

## 출처

- 그루 수: 서울특별시, [서울시 가로수 위치 정보(경도, 위도)](https://data.seoul.go.kr/dataList/OA-22904/S/1/datasetView.do) OA-22904 2026년판, 서울 열린데이터광장. 공공누리 제4유형. 원본은 저장소에 넣지 않고 수종별 합계만 적었다.
- 학명·과명·식물 특징: 국립수목원 [국가표준식물목록](https://www.nature.go.kr/kpni/index.do), [국가생물종지식정보시스템](https://www.nature.go.kr). 과명은 최근 분류(APG) 기준으로 적었다. 분류 체계에 따라 메타세쿼이아를 낙우송과, 칠엽수를 칠엽수과로 적기도 하므로 국가표준식물목록 표기와 한 번 더 대조한다.
- 카드 문장은 위 자료를 바탕으로 팀이 쉬운 말로 다시 썼다. 화면에는 "수종 정보: 국립수목원 국가생물종지식정보시스템 참고"를 함께 표시한다.
- 교육 카드·문제은행: TreeCare 서비스 규칙(`CLAUDE.md`, `용어.md`, `backend/db/ERD.md`)과 기준값(위 표)을 쉬운 말로 옮겼다. 폭염기 건강 수칙(물 자주 마시기, 더운 시간 피하기, 증상이 있으면 활동 중단)은 질병관리청 폭염 대비 건강수칙을 참고했다.
