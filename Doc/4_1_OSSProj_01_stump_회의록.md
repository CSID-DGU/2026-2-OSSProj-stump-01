- **참석자**: 김태형(팀장), 김양우, 김현, 오승현

### 의제 목록

1. 팀 결성 후 첫 회의
2. 사회혁신가님 제안 주제 검토
3. 필드트립 일정 및 연락 방법 논의
4. 사전 준비 사항

### 의제별 논의 요지

**의제 1. 팀 결성 후 첫 회의**

- 팀이 결성되고 처음으로 진행하는 회의인 만큼, 팀원 간 소개와 함께 앞으로의 프로젝트 진행 방향에 대해 이야기를 나눔

**의제 2. 사회혁신가님 제안 주제 검토**

- 사회혁신가님께서 제안하신 4가지 주제에 대해 각 주제의 내용과 구현 가능성을 함께 검토함

  2. 새 탐조
  3. 나무와의 정서적 교감
  4. 나무그늘
- 네 가지 주제 모두 도시의 나무·생태와 관련된 주제로, 시민 참여와 데이터 활용 측면에서 발전 가능성이 있다는 의견이 나옴
- 주제별로 필드트립에서 더 구체적인 이야기를 들어본 뒤 최종 방향을 정하기로 함

**의제 3. 필드트립 일정 및 연락 방법 논의**

- 필드트립 일정: 9월 15일 오후 5시로 결정
- 사회혁신가님과는 슬랙(Slack)을 통해 연락하여 일정을 조율하기로 함
- 필드트립 전 원활한 진행을 위해 사전 회의를 한 번 더 진행하기로 함

**의제 4. 사전 준비 사항**

- 필드트립 전 9월 13일에 회의를 진행하기로 함
- 각자 필드트립 때 사회혁신가님께 드릴 만한 질문이나 관심 있는 주제를 생각해 오기로 함

### 액션 아이템

1. 필드트립 때 할 만한 질문 생각해 오기
2. 희망 주제 및 우선순위 생각해 오기

### 공유사항 및 차기 회의 일정

- **회의결과**

## 2차 회의

- **안건**: 희망 주제 선정 및 전체적인 필드트립 준비
- **일시**: 2026년 9월 13일 일요일 오후 3시
- **장소**: 온라인 회의
- **참석자**: 김태형(팀장), 김양우, 김현, 오승현

### 의제 목록

1. 희망 주제 우선순위 선정
2. 필드트립 사전 준비 사항
3. 사회혁신가님께 드릴 질문 정리

### 의제별 논의 요지

**의제 1. 희망 주제 우선순위 선정**

- 1순위: 탐조 (도심 속 새를 관찰하고 기록하는 서비스)
- 2순위: 시민-나무 관계 (시민과 도시 나무를 연결하는 서비스)
- 3순위: 나무그늘 (도시 내 나무그늘 정보를 활용하는 서비스)
- 1순위인 탐조 주제를 중심으로 필드트립을 준비하되, 2·3순위 주제도 함께 검토할 수 있도록 준비함

**의제 2. 필드트립 사전 준비 사항**

- 탐조 관련으로 정리해 둔 자료를 각자 읽어보고 핵심 내용 정리
- 게임 구현에 필요한 요소를 유사 게임(포켓몬고, 피크민 블룸 등)을 참고하여 구상
  - 게임 진행 방식, 수집 요소, 사용자가 지속적으로 참여하게 만드는 보상 구조 등
- 필드트립 때 사회혁신가님께 드릴 질문 목록 작성

**의제 3. 사회혁신가님께 드릴 질문 정리**

1. 한계점이나 어려울 만한 점이 있을까요?
2. 비즈니스 모델은 어떻게 가져가야 할까요?
3. 사람들을 어떻게 유입시킬지 고민입니다.
4. 희귀종 관련 주의사항과 새를 촬영할 때 윤리적으로 주의할 점이 있을까요?
5. 초기 서비스에서 새의 범위를 어느 정도로 시작해야 할까요?
6. 새를 찍었을 때 어떤 정보를 제공하면 가장 유익할까요?
7. 축적한 조류 사진과 위치 데이터가 서울환경연합이나 생태연구진의 조류 모니터링 활동에 유용한 데이터로 쓰일 수 있을까요?
8. 서울환경연합이나 관련 단체에서 이미 하고 있는 조류 모니터링·기록 프로젝트나 데이터가 있을까요?

### 액션 아이템

1. 탐조 관련 자료 읽고 내용 정리
2. 유사 게임(포켓몬고, 피크민 블룸 등) 분석 후 게임 요소 정리
3. 필드트립 참석 후 피드백 내용 정리

### 공유사항 및 차기 회의 일정

- **회의결과**
  - 희망 주제 우선순위 확정 (1순위 탐조 / 2순위 시민-나무 관계 / 3순위 나무그늘)
  - 필드트립 질문 목록 8개 확정
- **차기 회의**: 2026년 9월 17일 (3차 회의)

## 3차 회의

- **안건**: 필드트립을 바탕으로 새로운 주제 탐색
- **일시**: 2026년 9월 17일 목요일 오후 12시
- **장소**: 온라인 회의
- **참석자**: 김태형(팀장), 김양우, 김현, 오승현

### 의제 목록

1. 필드트립 피드백 공유
2. 주제 후보 1: 시티트리클럽 개선
3. 주제 후보 2: 미세먼지 히트맵
4. 주제 후보 3: 도시 빗물 관리 지도

### 의제별 논의 요지

**의제 1. 필드트립 피드백 공유**

- 사회혁신가님 의견: 새를 탐조하는 것은 많은 어려움이 있음. 움직이는 새는 촬영하기 어렵고, 수요층의 니즈를 정확히 파악하지 못한다면 구현하기 어려울 것
- 문제 정의를 더 탄탄히 한 후, 수요층의 니즈를 파악하여 구현하는 것을 추천받음
- 피드백을 반영하여 탐조 주제를 보류하고 여러 새로운 주제를 탐색하기로 함

**의제 2. 주제 후보 1: 시티트리클럽 개선**

- 기존 시티트리클럽의 핵심 기능은 유지하면서 사용성·디자인·플랫폼을 개선하고, 사용자가 지속적으로 참여할 수 있는 요소를 추가
- 기존 서비스가 나무 사진 업로드·댓글·좋아요 중심의 SNS에 가까웠다면, 개선된 서비스는 사용자가 직접 주변 나무를 발견하고 기록하며 도시의 나무 데이터를 만들어가는 것을 목표로 함
  - **방향 A. 나무 데이터 기반 지도**: 확보된 나무 데이터를 지도에 표시하고 주변 나무 위치·사진·기록 확인, 방문 기록 및 관찰 내용 추가 → 도시의 나무를 탐험 가능한 데이터베이스로 구축
  - **방향 B. 사용자 직접 나무 등록**: 현재 위치 기반으로 나무 등록, 사진 촬영 및 정보 입력 (틀린 정보 입력 가능성 있음). 나무 간 거리가 가까워 GPS 오차로 정확한 위치 구분이 어려울 수 있음 + 재미요소 추가 필요

**의제 3. 주제 후보 2: 미세먼지 히트맵**

- 미세먼지 종합 히트맵을 구축하여 서울시와 시민의 공익에 기여
- 러닝 시간대 추천, 행동 강령 등 일반 시민 맞춤 서비스 제공

**의제 4. 주제 후보 3: 도시 빗물 관리 지도**

- 침수 위험 지역, 녹지, 투수면·불투수면 정보를 지도에서 확인하고, 녹지 확대·빗물정원·투수블록 설치에 따른 빗물 유출 저감 효과를 시뮬레이션하는 환경 서비스
- 기획 배경: 도시는 불투수면 비율이 높아 집중호우 시 빗물이 짧은 시간에 배수시설로 몰림 → 빗물 관리가 필요한 지역과 친환경 개선 방법의 효과를 직접 확인할 수 있는 서비스로 기획

### 액션 아이템

1. 시티트리클럽 관련 아이디어 각자 구상
2. 국내외 도시 나무 관련 유사 서비스 사례 조사

### 공유사항 및 차기 회의 일정

- **회의결과**
  - 세 가지 후보를 비교한 결과, 시티트리클럽 쪽 주제를 살려서 진행하기로 결정
- **차기 회의**: 2026년 9월 22일 (4차 회의)

## 4차 회의

- **안건**: 교수님과의 주제 관련 피드백
- **일시**: 2026년 9월 22일 화요일 오후 5시~7시
- **장소**: 정보문화관 P404호
- **참석자**: 김태형(팀장), 김양우, 김현, 오승현

### 의제 목록

1. 교수님과의 주제 관련 피드백 진행
2. 팀이 제시한 주제
3. 교수님 피드백
4. 교수님이 제안하신 새로운 방향
5. 팀 논의

### 의제별 논의 요지

**의제 1. 교수님과의 주제 관련 피드백 진행**

- 지난 회의에서 선정한 시티트리클럽 주제에 대해 교수님께 피드백을 받음

**의제 2. 팀이 제시한 주제**

- 시티트리클럽을 웹이나 앱으로 구현
- 흥미를 끄는 기능 추가: 사용자가 본인이 직접 가꾸는 정원이나 업적 달성을 위한 게임 요소
- 사용 데이터를 종합하여 대시보드를 만들어 지자체나 일반 시민에게 정보를 제공

**의제 3. 교수님 피드백**

- 이미 있는 웹을 앱으로 만드는 것은 불필요한 작업이라는 의견을 주심
- 단순히 기존 서비스의 플랫폼을 옮기는 것보다, 서비스가 제공하는 새로운 가치가 무엇인지가 더 중요하다는 점을 짚어주심

**의제 4. 교수님이 제안하신 새로운 방향**

- NFT라는 단어를 언급하시며, 나무에 새로운 가치를 부여해 나무를 색다른 관점으로 바라보는 주제를 제안하심
- 나무를 관리하고자 하는 시민을 모집하여 직접 지자체에 건의하고, 관리자 명단에 이름이 나오도록 하여 명예를 주는 주제를 제안하심

**의제 5. 팀 논의**

- 교수님 제안은 시민에게 소유권이 아닌 명예와 역할을 부여한다는 점에서, 시민과 나무를 장기적으로 연결하려는 기존 방향과도 잘 맞는다는 의견이 나옴
- 다음 회의에서 교수님 제안을 바탕으로 각자 구체적인 아이디어를 가져오기로 함

### 액션 아이템

1. 나무 명예관리인·생태적 가치 부여 관련 아이디어 각자 구체화
2. 국내외 가로수 입양·시민 참여 관리 사례 조사

### 공유사항 및 차기 회의 일정

- **회의결과**
  - 교수님의 의견을 수용하여 교수님이 말씀하신 쪽으로 방향을 잡기로 함
- **차기 회의**: 2026년 9월 24일 (5차 회의)

## 5차 회의

- **안건**: 시티트리클럽 관련 아이디어 제시
- **일시**: 2026년 9월 24일 목요일 오후 12시
- **장소**: 온라인 회의
- **참석자**: 김태형(팀장), 김양우, 김현, 오승현

### 의제 목록

1. 시티트리클럽 관련 아이디어를 내서 방향성 모색
2. 1안: 「서울 나무 명예관리인 / Tree Steward Pass」
3. 2안: 돌봄 기록 + 입양 웹 플랫폼

### 의제별 논의 요지

**의제 1. 시티트리클럽 관련 아이디어를 내서 방향성 모색**

- 시티트리클럽 관련 아이디어를 내서 방향성 모색 (아래 1안·2안)

**의제 2. 1안: 「서울 나무 명예관리인 / Tree Steward Pass」**

- 서울시 소유의 가로수 한 그루와 시민 한 명을 장기적으로 연결하고, 소유권이 아닌 '공식 명예관리인 자격'을 부여
- 구체화 8단계
  1. **나무 선택/배정**: 집·학교·직장 주변에서 관리 가능한 가로수 선택 또는 자동 배정
  2. **간단한 교육**: 물주기, 이상 징후, 해서는 안 되는 관리 행위 등 10분 내외 교육
  3. **명예관리인 위촉**: "가로수 ID / 명예관리인 이름 / 활동 기간" 형태의 디지털 인증서
  4. **정기 관찰**: 사진, 잎 상태, 가지, 수피, 토양, 쓰레기 등 기록
  5. **가능한 관리**: 물주기, 주변 쓰레기 제거 등 안전한 활동
  6. **이상 신고**: 병충해·상처·과도한 가지치기·뿌리 노출 등을 나무 ID와 함께 담당 부서로 전송
  7. **행정 알림**: 내 나무의 가지치기·정비·안전진단 등이 예정되면 알림
  8. **생애 기록**: 계절별 사진과 관리 이력이 한 그루의 '타임라인'으로 축적
- 명예관리인 권한: 관리계획 알림 수신, 공식 관찰기록 작성, 전용 신고경로, 가지치기·제거 등 중요 작업 예정 시 의견 제출

**의제 3. 2안: 돌봄 기록 + 입양 웹 플랫폼**

- 한 줄 컨셉: 시민의 돌봄 기록이 시에게는 가로수 관리 데이터가 되고, 입양자에게는 나무가 들려주는 이야기가 되는 웹 플랫폼
- 시티트리클럽의 정서적 관계(멜버른), 돌봄 참여 기록(베를린), 유료 입양·기념(해외 기념수 프로그램)을 하나의 흐름으로 연결
  - **입양자(유료)**: 나무를 입양해 이야기를 입히고 편지·나이테를 받음 (입양비 = 명판 제작 + 관리기금)
  - **돌봄 참여자(무료)**: 어떤 나무든 물·영양제를 주고 웹에 기록
  - **지나가는 시민(무료)**: 나무 앞 QR 명판을 찍어 나무에 입혀진 이야기를 읽음
  - **지자체 담당자**: 구청 녹지 부서가 대시보드로 관리 우선순위와 기금 집행 확인
- 입양 여부와 상관없이 누구나 돌봄 가능, 입양자에게는 나무의 상태 변화만 전달. QR 명판을 통해 동네에 "이야기가 있는 나무"를 만듦

### 액션 아이템

### 의제별 논의 요지

**의제 1. 완성된 주제: 서울 TreeMate 통합 기획서**

- 서울시가 개별 위치정보를 보유·공개하고 있는 가로수를 대상으로 한 시민 명예관리 서비스
- 슬로건: "서울의 나무 한 그루와 시민 한 명을 연결합니다."
- 공개된 가로수 위치 데이터를 활용함으로써, 이전 회의에서 우려했던 GPS 오차 및 잘못된 나무 정보 입력 문제를 줄일 수 있음

**의제 2. 한 줄 컨셉**

- 시민의 기록은 시에는 가로수 관리 우선순위가 되고, 시의 조치와 기금 사용은 다시 알림과 나이테가 되어 시민에게 돌아오는 웹 플랫폼

**의제 3. 두 안의 통합 구성**

- 1안: 정서(이야기·나이테)와 경제(입양비·관리기금) 시스템
- 2안: 시민 관찰 데이터, 이상 신고 처리, 관리 사각지대 대시보드
- 두 안의 핵심 요소를 하나의 순환 구조로 연결 → 멜버른의 정서적 관계, 베를린의 돌봄 기록, 해외 기념수 프로그램의 유료 입양이 이 구조 안에서 함께 작동
- 시민(기록·신고) → 시(관리 우선순위 판단·조치·기금 집행) → 시민(알림·나이테 수령)으로 이어지는 흐름을 서비스의 중심 구조로 정리

**의제 4. 중간발표 준비**

- 중간발표 자료에 대해 토의하고, 발표에서 어떤 틀과 기능을 중점적으로 살릴지 회의
- 발표 흐름 가안: 문제 정의 → 참고 사례 → 서비스 구조(순환 구조) → 주요 기능 → 기대 효과
- 필드트립 피드백을 반영하여 문제 정의와 수요층(시민·입양자·지자체)의 니즈를 명확히 드러내는 방향으로 구성하기로 함
