# 🌳 서울 TreeMate
> 서울시 가로수 시민 명예관리 웹 플랫폼

2026-2 오픈소스소프트웨어프로젝트 | 팀 **Stump** (01팀)

## 📌 프로젝트 소개
서울 TreeMate는 서울시 공공데이터의 가로수를 시민이 **명예 입양**하고 **물주기·관찰·이상 신고**를 기록하는 웹 플랫폼입니다.
시민의 기록은 구청 대시보드에서 관리 대상이 되고, 구청의 조치 결과와 관리기금 사용 내역은 **알림**과 **디지털 나이테**로 시민에게 다시 돌아옵니다.

> 시민의 기록 → 나무 상태 → 구청 확인·조치 → 시민 피드백

## 💡 목적과 동기

폭염과 가뭄으로 가로수의 수분 스트레스는 커지고 있지만, 구청은 한정된 인력으로 많은 나무를 관리해야 해서 어떤 나무에 물이 필요한지, 어디에 이상이 생겼는지 실시간으로 알기 어렵습니다.

반면 가로수를 아끼는 시민은 많지만, 그 마음은 일회성 돌봄 활동에 머물고 **관리 데이터나 관리 재원으로 이어지지 않습니다.** 국내외에 나무와의 정서적 관계, 돌봄 기록, 기념수 같은 재원, 행정 피드백을 각각 다룬 사례는 있지만, 이것들을 하나로 잇는 구조는 없었습니다.

TreeMate는 흩어진 **시민의 애착**을 **관리 데이터와 재원**으로 바꾸어, 시민 참여가 일회성에 그치지 않고 실제 가로수 관리로 이어지게 하는 것을 목표로 합니다.

### 주요 기능
- **나무 지도 / QR 나무 이야기 페이지**: 가로수 위치와 상태 확인, 로그인 없이 열람
- **기록 3종**: 물주기 · 관찰 · 이상 신고
- **나무 상태 계산**: 기상청 강수·기온과 물주기 기록으로 물 필요도 추정
- **입양**: 입양 신청(모의 결제), 교육 이수, 이야기 입히기, 디지털 나이테
- **구청 대시보드**: 이상 신고 처리 큐, 물 부족 나무, 시민 관찰 공백, 관리기금 현황
