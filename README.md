# 2026-2-OSSProj-stump-01
# 🌳 서울 TreeCare
> 서울시 나무돌보미 연계 가로수 시민 돌봄 서비스

2026-2 오픈소스소프트웨어프로젝트 | 팀 **Stump** (01팀)

## 📌 프로젝트 소개
서울 TreeCare는 서울시 나무돌보미 사업을 토대로 **가로수 한 그루와 시민 한 명을 잇는** 시민 돌봄 서비스입니다.
시민은 돌보미로 신청하고 물품을 받아 나무를 돌보며, 날짜별 활동 기록을 **월간 보고서**로 냅니다. 구청은 그 보고서를 한 화면에서 검토해 **봉사시간**을 기록하고 상부에 보고합니다. 그 한 달의 돌봄은 나무의 **이야기**와 **디지털 나이테**로 쌓입니다.

> 신청·물품 → 날짜별 활동 기록 → 월간 보고서 → 구청 검토·봉사시간 → 나이테

서비스는 설치 없이 쓰는 **시민 모바일 웹(PWA)** 과 **구청 웹**으로 나뉩니다.

## 💡 목적과 동기

서울시에는 시민·단체가 가까운 가로수를 돌보는 나무돌보미 제도가 있습니다. 2026년 10월 중구청 수목관리 주무관 면담에서 현장의 실제 불편을 확인했습니다.

- **구청**: 돌보미 활동 일지를 한글 문서로 받아 하나씩 읽고 정리해 상부에 보고하고, 봉사시간을 따로 기록합니다. 신청서와 물품도 따로 처리합니다.
- **시민**: 신청과 물품 준비가 번거롭고, 활동해도 기록이나 의미로 남지 않아 참여가 일회성에 그칩니다. 올해는 폭염으로 신청자가 거의 없었습니다.
- **지나가는 시민**: 예전의 돌보미 명패가 없어져, 나무 앞에서 그 나무의 이야기를 볼 방법이 없습니다.

TreeCare는 이 행정 절차를 시민 웹과 구청 웹으로 옮기고, 나무 이야기와 디지털 나이테 같은 정서적 보상으로 참여가 이어지게 하는 것을 목표로 합니다.

> 1차 제안 발표의 원안(서울 TreeMate: 유료 입양·물주기 기록·관리기금)에서 구청 면담과 서울환경연합 피드백을 반영해 2026-10-29 주제를 바꿨습니다. 자세한 내용은 [중간보고서](./Doc/2_1_OSSProj_01_stump_중간보고서.pdf)에 있습니다.

## ✨ 주요 기능

**시민 모바일 웹 (PWA)**
- **돌보미 신청·물품 신청**: 지도에서 나무를 골라 신청서 제출, 활동 물품 신청(반납 없음)
- **날짜별 활동 기록**: 리뷰 쓰듯 사진 + 선택 항목 + 짧은 글로 기록, 기록하면 나무의 고마워요 반응과 스탬프
- **월간 보고서 자동 작성**: 기록한 날짜를 고르면 구청 양식으로 자동 작성·제출, 내 봉사시간 확인
- **나무 지도·상세 / QR 나무 이야기 페이지**: 수종별 기본 콘텐츠, 여러 돌보미가 함께 쓰는 나무 이야기, 설치·로그인 없이 열람
- **오늘의 날씨**: 활동 추천 시간과 폭염특보 안내
- **이상 신고**: 구청 처리 큐로만 전달, 조치 결과는 알림으로
- (Should) 디지털 나이테, 배지·활동 순위, 지나가는 시민의 좋아요·한 줄 응답, 단체 계정

**구청 웹**
- **한눈에 보기**: 검토 대기 보고서, 미제출 돌보미, 승인 대기 신청·물품, 미처리 신고, 이달 봉사시간
- **신청 심사 / 보고서 검토·봉사시간 기록 / 물품 지급 관리 / 이상 신고 처리**
- (Should) 상부 보고용 월별·지역별 집계 내려받기, 단체별 필터
